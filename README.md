# Akakçe Web UI Test Automation Project

This repository features a robust Web UI Test Automation Framework designed to test the core functionalities of the Akakçe e-commerce price comparison platform. It is built to demonstrate professional software quality assurance practices using industry-standard tools.

## 🚀 Key Learning Objectives & Implemented Features
*   *Locators & Elements:* Mastery of identifying complex UI elements using advanced XPath and CSS Selectors.
*   *Synchronization:* Efficient use of Implicit, Explicit, and Fluent Waits to handle dynamic page elements and prevent flaky tests.
*   *Actions Class:* Automated advanced user interactions including mouse hover actions, drag-and-drop, and double-clicks.
*   *Verification & Assertions:* Comprehensive implementation of Hard and Soft Assertions to validate expected outcomes against actual behavior.
*   *Report & Troubleshooting:* Integrated automated screen capture (Screenshots) functionality upon test failures for quick debugging.

## 🛠️ Tech Stack & Tools
*   *Language:* Java
*   *Automation Tool:* Selenium WebDriver
*   *Build Tool:* Maven
*   *Test Execution:* JUnit / TestNG framework structures

## 📋 Sample Test Scenarios Covered
1.  *User Authentication:* Validating registration, login, and error handling for invalid credentials.
2.  *Product Search & Filtering:* Testing the search engine accuracy and verifying price/brand filters.
3.  *UI Verification:* Ensuring all main navigation headers and product detail pages display correctly without breaks.

---
Note: This project was developed as part of a comprehensive 6-month QA Automation Engineering program to implement hands-on UI testing strategies on live web applications.
